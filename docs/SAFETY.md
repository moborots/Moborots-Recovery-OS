# سیاست ایمنی

Moborots Recovery OS برای عیب‌یابی و پشتیبان‌گیری مجاز از سیستم‌هایی طراحی شده که مالک آن‌ها هستید یا اجازه مدیریتشان را دارید.

## اصول

- ابزارهای فهرست دیسک و اطلاعات سیستم فقط اطلاعات را می‌خوانند.
- برنامه فعلی هیچ دستور قالب‌بندی، حذف پارتیشن یا نوشتن مستقیم روی دیسک اجرا نمی‌کند.
- SMART برای مشاهده وضعیت سلامت دیسک استفاده می‌شود.
- ابزار پشتیبان‌گیری فایل‌ها را کپی می‌کند و نباید فایل مبدأ را حذف کند.
- پیش از هر عملیات بازیابی یا تعمیر فایل‌سیستم، نسخه پشتیبان تهیه کنید.

## خارج از محدوده پروژه

- شکستن، حدس‌زدن یا دور زدن رمز عبور
- استخراج یا تحلیل هش رمز عبور
- تغییر یا دست‌کاری SAM و اطلاعات احراز هویت
- دسترسی به داده‌های افراد بدون مجوز

گزارش آسیب‌پذیری یا رفتار ناامن را از طریق GitHub Issues ارسال کنید.
