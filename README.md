# Moborots Recovery OS

**Moborots Recovery OS** یک محیط بازیابی و عیب‌یابی مستقل، قابل بوت و متن‌باز برای سیستم‌های x86_64 است. هدف پروژه ارائه ابزارهای گرافیکی و ساده برای بررسی وضعیت سیستم، مشاهده دیسک‌ها، عیب‌یابی شبکه و پشتیبان‌گیری از فایل‌هاست.

> وضعیت فعلی: نسخه اولیه در حال توسعه است؛ هنوز ISO نهایی ساخته و آزمایش نشده است.

## ویژگی‌های هدف

- اجرای مستقل از ویندوز و بدون نیاز به نصب روی دیسک
- رابط گرافیکی فارسی و انگلیسی با Python و PySide6
- نمایش مشخصات سخت‌افزار و سیستم
- نمایش دیسک‌ها، پارتیشن‌ها و فضای ذخیره‌سازی
- مشاهده اطلاعات سلامت دیسک با SMART (در صورت پشتیبانی سخت‌افزار)
- ابزار پشتیبان‌گیری و کپی فایل‌ها
- نمایش اطلاعات شبکه و وضعیت اتصال
- قابلیت اجرا در VMware و بوت از USB روی کامپیوتر واقعی

## فناوری‌ها

- Debian Live (x86_64)
- XFCE Desktop
- Python 3 و PySide6
- ابزارهای استاندارد Linux مانند lsblk، smartmontools و NetworkManager

## اجرای برنامه در محیط توسعه

در Debian یا Ubuntu:

```bash
sudo apt update
sudo apt install -y python3 python3-pyside6.qtwidgets python3-pyside6.qtcore python3-pyside6.qtgui
python3 app/main.py
```

## ساخت ISO بوتیبل

ساخت ISO در یک محیط Debian/Ubuntu x86_64 انجام می‌شود. مراحل کامل در [راهنمای ساخت ISO](docs/BUILD.md) آمده است.

به‌طور خلاصه:

```bash
sudo apt update
sudo apt install -y live-build debootstrap squashfs-tools xorriso
./boot/build_iso.sh
```

خروجی مورد انتظار در پوشه `output/` قرار می‌گیرد.

## ساختار مخزن

```text
app/       برنامه گرافیکی و ماژول‌های ابزار
boot/      اسکریپت‌های پیکربندی و ساخت ISO
config/    فایل‌های پیکربندی Debian Live
docs/      راهنماها و مستندات
scripts/   ابزارهای کمکی
```

## نکات ایمنی

- ابزارهای اولیه برای مشاهده اطلاعات دیسک و SMART به‌صورت فقط‌خواندنی طراحی شده‌اند.
- عملیات پشتیبان‌گیری فقط فایل‌ها را از مبدأ به مقصد کپی می‌کند.
- هیچ قابلیت شکستن، حدس‌زدن یا استخراج رمز عبور، تحلیل هش یا دست‌کاری اطلاعات احراز هویت در محدوده این پروژه نیست.
- قبل از هرگونه تغییر روی پارتیشن‌ها یا فایل‌سیستم‌ها، از داده‌های مهم نسخه پشتیبان تهیه کنید.
- این پروژه جایگزین ابزارهای تخصصی بازیابی اطلاعات نیست.
